# Advanced Audio Manager — releases

Versões compiladas (portáteis, sem instalação) do **Advanced Audio Manager** para Windows.

- Descarregue o `.zip` da [última versão](https://github.com/LittleLion/AdvancedAudioManager-releases/releases/latest), extraia para uma pasta do utilizador e abra `AdvancedAudioManager.exe`.
- A app atualiza-se sozinha a partir deste repositório (sem token).
- Cada pacote tem um ficheiro `.sha256`, verificado pela app antes de instalar.

Este repositório só contém releases; o código-fonte é privado.
